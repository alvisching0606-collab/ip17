# WEB 版記帳對話機器人

一個純前端記帳助理，可用自然語言或 OCR 單據文字建立每日消費帳目，並依每日、每週或每月範圍產生可下載的 CSV / PDF 報告。

## 功能

- **對話記帳**：輸入「今天午餐 120」「昨天交通 45」即可自動解析日期、品項、類別和金額。
- **OCR 匯入**：上傳收據、發票或付款截圖，以瀏覽器端 Tesseract.js 進行文字辨識；會優先判斷「銀碼 / 金額 / 現金 / VISA / MASTER」等付款金額行，也可直接貼上單據文字。
- **報告產生**：支援每日、每週、每月摘要，顯示總額、筆數、支付方式與類別排行。
- **檔案下載**：一鍵匯出 `.CSV` 或 `.PDF`，方便留存或交給會計流程。
- **本機資料**：帳目儲存在瀏覽器 `localStorage`，不需後端即可試用。

## 使用方式

```bash
npm start
```

開啟瀏覽器至 `http://localhost:4173`。
